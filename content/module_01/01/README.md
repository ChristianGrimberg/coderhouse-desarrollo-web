# ¿Qué es HTML?

HTML es un __lenguaje de marcado__ que se utiliza para estructurar el contenido en la web. Esto significa que con HTML puedes organizar textos, imágenes, enlaces y secciones para que los navegadores web los interpreten y muestren correctamente. A diferencia de un lenguaje de programación, HTML no realiza cálculos ni lógica, sino que define la estructura y el significado del contenido.

> __Dato importante__: El término "marcado" se refiere a las etiquetas que rodean el contenido para indicar su función o tipo.

## Diferencia entre contenido y presentación

Es fundamental entender que HTML se encarga del contenido y su estructura, mientras que la presentación (colores, fuentes, diseño) se maneja con otros lenguajes como CSS. Por ahora, nos enfocaremos en cómo organizar el contenido correctamente.

## Estructura básica de un documento HTML

Un documento HTML tiene una estructura mínima que todo archivo debe seguir para que los navegadores lo interpreten bien. Esta estructura incluye:

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Título de la página</title>
  </head>
  <body>
    <!-- Aquí va el contenido visible -->
  </body>
</html>
```

* `<!DOCTYPE html>`: Indica al navegador que este es un documento HTML5.
* `<html>`: Elemento raíz que contiene todo el contenido.
* `<head>`: Contiene metadatos, como el título y la codificación.
* `<body>`: Contiene el contenido visible para los usuarios.

Cada una de estas partes es esencial para que la página funcione correctamente.

## Herramientas: editor y navegador

Para crear y ver tus páginas HTML necesitarás:

* __Editor de código__: Un programa donde escribirás tu código. Recomendamos VSCode, que es gratuito y fácil de usar.
* __Navegador web__: Para abrir y visualizar tus archivos HTML. Puedes usar Chrome, Firefox o Edge.

Con estas herramientas, podrás escribir tu código y ver los resultados en tiempo real.

> __Conocimiento clave__: HTML es la base para crear páginas web, y entender su estructura básica es el primer paso para convertirte en desarrollador web.
